# Варианты мягких SFX

Каждый пример идёт в одинаковом порядке: клик → информация → успех → ошибка.
Громкость выровнена, тональные атаки плавные, резких волн нет.

- `01-glass.wav` — тихие стеклянные тоны с коротким хвостом.
- `02-warm.wav` — более тёплые и низкие, почти без послезвучия.
- `03-air.wav` — воздушные колокольные тоны с лёгким хвостом.
