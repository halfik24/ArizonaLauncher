# BETA.3 — план работ

> Составлен 11.11.2026 по фактическому коду (сборка/тесты не запускались).
> Ветка: `main`, версия в `tauri.conf.json` — `2.0.0-beta`.
> Правило beta.3: только UX, визуал и восстановление уже написанного. Новых
> полуготовых механик не добавляем.

---

## 0. Контекст

Патчи v2 от EIR ещё не вышли. Патчи v1 намеренно отключены: старый
`ArizonaPatches.dll` (1.0.0.0) вызывал краши игры, лаунчер его переименовывает
(`disable_old_dll`, `launcher.rs:2713`). Поэтому:

- настройки патчера **должны редактироваться** (это заготовка под v2);
- скачивание/обновление патчей из UI **должно быть недоступно**;
- плашка «Обновить сейчас» **удаляется**.

Air-лаунчер не обязателен: есть нативный запуск. Установка Air предлагается
только когда в настройках выбран «Через лаунчер Air», а в папке игры его нет.

## 1. Подтверждённые факты

### 1.1. Drag & Drop

- Приём файлов реализован полностью: `src/index.html:16620-16751`
  (оверлей, лимит 5 МБ, base64, `.lua` и `.json`, установка).
- В `src-tauri/tauri.conf.json` у окна (`app.windows[0]`, строки 11-26) нет
  `"dragDropEnabled": false`.
- На Windows нативный обработчик Tauri перехватывает drop, HTML5-события в
  webview не доходят. В браузере/CDP всё работает — отсюда «фича потерялась».
- В `src-tauri` нет ни одного `drag_drop`/`onDragDropEvent` — нативный путь
  тоже не подключён.

### 1.2. Настройки патчера

- `renderPatchStatusUI` (`index.html:13228-13297`) в начале всегда прячет
  кнопки (`13236-13237`), а панель `#checkboxGroup` показывает только при
  `status === 'current'` или при дебаг-флаге (`13287`).
- `downloadPatches()` (`13299`) и `checkPatchesUpdate()` (`13372`) не имеют
  вызовов — мёртвые.
- Баннер «Обновить сейчас» (`14083-14110`) вызывает `loadPatchSettings()`, а та
  (`13218-13220`) делает только `loadPatchPresets()` — ничего не обновляет.
- Автопроверка обновлений патчей: `13200-13212`; второй вызов баннера —
  `18915` (`window._onPatchesUpdateAvailable`).
- `read_patches` (`launcher.rs:2827-2843`) при отсутствии файла возвращает
  `success:false`, из-за чего фронт ставит `_patchesReadFailed` (`16329`) и
  блокирует сохранение (`16481-16490`).
- Запись идёт в `preloading_plugins/#ArizonaPatches.json`
  (`patches_json_path`, `launcher.rs:2431`), папка создаётся
  (`write_patches_inner`, `2982-2984`).
- Признак «preloading установлена» — папка существует и непуста:
  `launcher.rs:1677-1681` и `has_preloading_plugins` (`4584`). Один
  сохранённый конфиг сделает папку «непустой».
- `install_action_for_folder` (`1703-1714`): «v8 есть, preloading нет» →
  `action: "none"` — установить preloading невозможно, `start_launcher_install`
  (`4686`) отказывает на `none`.

### 1.3. Air-лаунчер

- URL уже правильные: `launcher.rs:4366-4371`
  - `https://raw.githubusercontent.com/halfik24/ArzLaunchRepo/main/others/ArizonaLauncher8.0_byAIR.zip`

- После установки вызывается `checkLauncherInstallation(true)` без `gamePath`

### 1.4. Прочие дефекты, попавшие в план

- `_dbgForcePluginOn()` — дебаг-заглушка показа настроек патчей (`8497`).
- `v7_vulkanPair` ищется (`16396`), но элемента в разметке нет.
- `hide_window` (`15314`) — команды нет ни в bridge, ни в Rust.
- `#toastContainer` (`7530`) не используется, уведомления идут в

- `.json` при drag&drop перезаписывает патчи без подтверждения.
- `dragCounter` может залипнуть при отмене drag за пределами окна.
- `install_patches_file` считает bool через `is_some()` (`3610`),
  `import_patches` — через `unwrap_or(false)` (`3540`).

## 2. Принятые решения

1. Настройки патчера сохраняются **в папку игры**
   (`preloading_plugins/#ArizonaPatches.json`), как и раньше. Определение
   установки preloading чинится, чтобы один конфиг не считался установкой.
2. Скачивание патчей остаётся в коде, но не вызывается из UI. Точка
   включения — один флаг на фронте.
3. Плашка «Обновить сейчас» удаляется целиком вместе с автопроверкой. Баннер
   статуса на вкладке патчей остаётся, но без кнопок и без «настройки скрыты».
4. Air-установка не блокирует ничего. Меню установки — inline-блок в
   настройках, вкладка «Запуск». Открывает существующую модалку установки.
5. Все fallback-ссылки `worteng` переводятся на `halfik24` с теми же путями.
